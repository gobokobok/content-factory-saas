### Storyboard — lock-in warning and visual source model (design question)

- **C18 — Warn that the run style cannot be changed after the storyboard is generated.** On the Storyboard
  step, before generating, show a warning: once the storyboard is generated the run's style can no longer be
  changed. Reason: style determines whether scenes use stock or generated images, and AI generation adds
  extra storyboard data (continuity bible: characters, places, etc.).
- **C19 — OPEN DESIGN QUESTION: separate "style" from "image source".** Operator's idea: today Animated is
  tied to AI-generated images. But an *animated* (drawn/illustrated) run could also be sourced from **stock**
  resources. So there should be two independent choices, both set in **Run Settings**:
  1. Look: Realistic / Animated
  2. Image source: **Stock** (platform searches stock libraries) / **AI-generated** (storyboard worker +
     image generation)
  - If *AI-generated* is **not** selected → no characters / places / continuity-bible assets are produced for
    the storyboard.
  - If *AI-generated* **is** selected → those fields appear and the model generates the run's assets.
  - Once the storyboard/assets have been generated, changing this option should be **blocked** (or require an
    explicit "discard and regenerate" action).
  - Operator asked me to think about the best model when we plan these changes and to give a recommendation
    (implications for the existing D108 animation mode: visual mode currently = stock | animation, with
    animation implying AI images). *Status: needs a recommendation at planning time.*

## Follow-up investigation: which storyboard prompt for the Realistic (stock) flow

- **C35 — Prompt comparison (operator request, 2026-10-11).** Confirmed: the two modes use different workers
  and prompts. Stock: `cf_platform/workers/storyboard_worker.py`, prompt v0.17, Sonnet 4.6, single call with
  no extended thinking, then a Haiku review pass and a deterministic patcher. Animation:
  `cf_platform/workers/animation_storyboard_worker.py`, prompt an-v0.1 (Visual Director v4.1 adapted),
  Sonnet 5.5 adaptive thinking, effort high, no review pass.
  - The stock prompt has no narrative analysis, no concept step, no shot-variety or rhythm rules, no
    "reject generic imagery" rule. Scenes are cut mainly by word budget and sentence boundaries; queries
    are derived line by line. It is strong where acquisition needs it: three-tier fallback queries, domain
    anchoring (`global_context`, `avoid`), Character/Event segment types with Wikipedia/Wikimedia
    acquisition, on-screen-text typing, SFX vocabulary, format-conditional pacing, list/section rules.
  - The Visual Director prompt cannot be dropped in as is: it outputs `ai_prompt`, shot size/angle,
    continuity bible and motion, and none of the fields stock acquisition needs (`primary_stk` /
    `context_stk` / `concept_stk`, `segment_type`, `person_name`, `semantic_context`). It also composes
    shots that stock footage cannot supply ("low-angle medium shot of the learner leaning back") and uses
    1–5 s scenes for both formats, where stock portrait is tuned to 1.5–3 s.
  - **Recommendation:** keep the stock output contract and worker; port the Visual Director *method*
    into a new stock prompt version (v0.18) and run the same model setup as Animation (Sonnet 5.5, adaptive
    thinking). Ported: narrative beats analysis, concept-before-query, factual accuracy / no generic
    imagery, shot-variety and rhythm expressed as *search intent* (wide establishing vs detail vs human
    reaction), narration-fit rule, final self-check. Kept: segment types, three-tier queries, semantic
    context, OST typing, SFX, pacing, list and section rules, reviewer. Validate on one real script and
    timestamps side by side (v0.17 vs v0.18) before switching the default.
  - Not verified: no output of either prompt was run for this comparison; the assessment comes from
    reading the code and prompts. The P11 `visual_director_worker` (stock shot planner) exists but is only
    wired in `orchestrator/full_pipeline.py`, not in the Studio storyboard route.

- **C35 decision (operator, 2026-10-11): approved.** Keep the stock worker and contract; build prompt v0.18 on
  Sonnet 5.5 with adaptive thinking, porting the Visual Director method (beat analysis, concept before
  query, no generic imagery and factual accuracy, shot variety expressed as search intent, final
  self-check). Segment types, three-tier queries, semantic context, reviewer and pacing stay unchanged.
  The default is switched only after a side-by-side test (v0.17 vs v0.18) on one real script with timestamps.
